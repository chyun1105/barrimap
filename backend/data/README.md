# Map Graph Cache

`map_cache.graphml`은 2026-10-26 Geofabrik 대한민국 OSM 추출본에서 서울대학교 관악캠퍼스 중심(위도 37.4599, 경도 126.9519) 반경 3km의 보행 네트워크를 추출한 그래프입니다. 보행 접근 태그와 계단, 노면, 점자블록 관련 태그를 포함합니다.

지도 데이터 © OpenStreetMap contributors, ODbL 1.0. 데이터 출처: [Geofabrik South Korea](https://download.geofabrik.de/asia/south-korea.html).
